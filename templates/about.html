ℹ️ About Evidence Chain

Evidence Chain is a secure digital forensics system designed to ensure the integrity, traceability, and transparency of uploaded evidence files.

🧩 Technologies Used

  • Python Flask — Backend web framework
  • SQLite — Lightweight local database for ledger and user records
  • SHA-256 — Cryptographic hashing for file integrity verification
  • Isolation Forest (AI) — Machine learning algorithm for anomaly detection
  • HTML, CSS, JavaScript — Frontend design and dynamic interactions

🔒 Integrity Detection

Every evidence file uploaded is hashed using SHA-256. If a file is modified later — even by a single bit — its hash will change, and the system will immediately detect the tampering.

📈 Blockchain-Linked Ledger

Each evidence block links to the previous one through its hash chain, maintaining a tamper-evident audit trail.
